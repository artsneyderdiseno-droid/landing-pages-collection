# Landing pages collection

A collection of single-page websites I designed and built for events, brands and people.

## ✨ Highlights

- `bogomtb`, `bogoruta`, `bogochicas`: cycling community pages in Bogotá (mountain, road and women's community)
- `bogokids`: learn English by bike, a kids' program
- `sc`: S&C Digital Print, promotional products and POP material
- `eliana-castro`: personal page for a systems engineer (IT infrastructure & cloud)
- `luisa`: Creaciones Luisart, handmade art
- `sneyder-art`: my art page
- `calculadora`: material optimization calculator for print production
- Each folder is a standalone page: open its index.html

## 🚀 Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
